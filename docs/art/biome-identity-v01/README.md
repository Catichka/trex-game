# Approved grasslands fallen trees

Approved by Catherine on 19 October 2026. See CLAUDE_HANDOFF.md for the grasslands-only integration request and protected volcano constraint.

Production PNG/JSON pairs are in assets/obstacles/fallen-trunk and assets/obstacles/fallen-trunk-branch. Native dimensions: 54×24 and 54×39. The preview images show these exact sprites drawn beside the original small rock, small log and T-Rex with the game's current renderer. No production logic or manifest changes are included.

Sprites were produced with built-in image generation, then extracted and packed at native game resolution using nearest-neighbour sampling and a limited palette. Prompt: two cute warm-brown fallen trunks with golden cut ends, moss, a tall snapped branch on the second, crisp low-resolution arcade styling, transparent background, no scenery or text. Existing character/background assets were preserved.
