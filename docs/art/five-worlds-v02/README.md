# T-Rex Game — Five Worlds Balanced V02

35 game-ready transparent/opaque PNG layers (7 per world), five environment JSON files, five 2x previews, a comparison sheet, and integration instructions.

All layers are 480x200, with pixel-hard edges, y=152 ground, and horizontally repeating scenery. This is a playable **style/contrast prototype**, not a finished recreation of the concept illustration. The five environments use different motifs, compositions and palettes. The art is deliberately less busy around the player corridor.
