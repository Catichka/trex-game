# The T-Rex Game — Caveman V01

Game-ready **prototype** pixel-art sprites: 33 individual 48×48 transparent PNGs, atlas (384×336), JSON metadata, preview, and Claude handoff.

Animations: run 8, idle 4, jump 6, hurt 3, caught 4, defeated 4, respawn 4.

This is a simplified pixel-art implementation of the approved expressive caveman concept, **not** a faithful extraction of the detailed concept painting. Visual polish remains for a later iteration.

Render with nearest-neighbour scaling and preserve the game's existing hitbox and physics.
