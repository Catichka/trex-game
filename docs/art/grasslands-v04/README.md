# The T-Rex Game — Grasslands Production V04

A **game-ready technical asset pack** based on Claude's integration contract.

## Contents
1. T-Rex `rawr` animation (4 new 64×64 frames, 10 fps loop), appended to full compatible atlas.
2. Grasslands obstacles: rock-small, rock-large, log, cactus-small, cactus-large.
3. Seven full-frame 480×200 parallax layers and environment.json.
4. Three 6-frame one-shot effects: dust, chomp, catch.
5. Preview and Claude integration handoff.

Style: limited-colour chunky pixel art, genuine alpha for non-sky layers,
pixel-hard edges, nearest-neighbour rendering.

All art is original procedural game art and can be freely modified for this project.
