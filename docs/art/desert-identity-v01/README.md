# Desert sandstone — approved art

Approved by Catherine on 19 October 2026. Two distinctive layered sandstone sprites replace shared grey rocks in desert only, while existing cactus stays.

Production PNG/JSON pairs: assets/obstacles/sandstone-slab (15×12) and assets/obstacles/sandstone-butte (27×24). See CLAUDE_HANDOFF.md for integration. Native and 3× previews use the actual game draw functions, T-Rex, background and cactus assets. No production manifest, logic or existing asset changes are included.

Generation: built-in image generation, then sprite extraction and nearest-neighbour packing at native resolution. Prompt requested a low flat-topped eroded sandstone slab and a chunky miniature desert butte, readable horizontal strata, terracotta shadows, golden peach highlights, cute crisp arcade pixel art, transparent background and no scenery/text. Original character and environment assets are unchanged.
